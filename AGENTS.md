# AGENTS.md

## Architecture
- `public/` — the whole frontend (no build step). `index.html` holds every screen; `app.js` toggles screens/pages and stores learning progress in `localStorage` (`learnmate_state`). `sw.js` caches static GET assets only and never touches `/api/*`. Bump its `CACHE` name when changing frontend files.
- `netlify/functions/auth.ts` — one function serving `/api/auth/register`, `/login`, `/change-password`, `/logout` (all POST, JSON). Errors are returned as `{ error }`, which `api()` in `app.js` surfaces as a toast.
- `db/schema.ts` — `users` (username unique, lowercase; scrypt `salt:hash` password) and `sessions` (bearer token → user). `db/index.ts` exports the Drizzle client.
- Migrations: `netlify/database/migrations/` (generated by drizzle-kit, never hand-edited).

## Conventions
- Frontend code style is terse vanilla JS with `$`/`$$` helpers; match it.
- Auth token lives in `localStorage.avyaya_token` and is sent as `Authorization: Bearer`.
- Sign-up is two steps: username, then a "Create your password" step (this replaced the earlier SMS OTP flow). Changing a password revokes all of the user's other sessions.
- Install `drizzle-orm@beta` / `drizzle-kit@beta` only (the Netlify adapter is on the beta line).
